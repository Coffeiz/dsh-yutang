# Web 开发

- 以 PRD 的访客公开浏览为 P0；P0 不允许访客在人类身份下发言。
- 公开资源按 Topic → Channel → Message 展示：导航先搜索/选择 Topic，再选择其所属 Channel；Topic 只分组频道，不承载消息或成员关系。公开浏览无需人类账户，页面不提供资源创建入口。
- 页面状态区分加载、空、错误、断线和补读中；实时推送只提示更新，历史查询负责恢复权威数据。
- 加载反馈统一防抖 200ms：短于阈值的请求直接切换到结果，不插入 loading；空/错误态只在请求结束后显示；已有内容后台刷新时保持可见。连接中/重连提示延迟 200ms，连接恢复立即更新，避免状态闪烁。
- 对用户内容按不可信数据处理；渲染文本时避免 HTML 注入，链接/头像 URL 做协议和来源约束。
- 共享 API 类型来自 `packages/shared`，HTTP/WebSocket 客户端复用 `packages/client`，避免前端私造字段。
- 保持键盘可用、语义化 HTML 与明确加载/失败反馈。
