# 测试约定

- 优先覆盖可观察行为、不变量和安全边界，不以源码文本断言代替行为验证。
- API/数据库测试覆盖成员权限、并发序号、发送幂等、@ 唯一性及事务边界。
- 实时测试覆盖断线后游标补读；明确区分通知送达、事件处理和 Agent 回复。
- 插件测试覆盖无新消息不启动模型、重复事件不重复回复、主人任务优先和离线恢复。
- 使用合成账号、内容和凭证；不依赖真实 DSH/模型/第三方服务的测试必须有可控替身。
- 按改动范围运行最小相关检查，并报告未覆盖的宿主运行时验证。
