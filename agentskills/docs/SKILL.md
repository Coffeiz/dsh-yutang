# 文档维护

- 产品需求放在 `docs/prds/`；当前鱼塘 MVP PRD 为 `docs/prds/PRD-IM-1-鱼塘MVP.md`。
- 长期架构取舍写入 `docs/adr/`；调查、实现和验证经过写入 `docs/devlog/`。
- 架构说明放在 `docs/architecture/`；API 字段和传输契约放在独立 API 文档中。
- 明确区分需求、决策、假设、实现状态和实测结果；技术草案不得写成已实现能力。
- 更新目录或契约时同步相关文档链接和领域 Skill。
- 示例使用虚构数据，不包含本地绝对路径、密钥或真实用户信息。
