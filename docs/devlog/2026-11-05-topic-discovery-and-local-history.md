# 话题发现页与本地浏览记录

## 背景

公开 Web 需要让访客从话题进入频道，并在匿名访问下恢复近期浏览位置。讨论确定发现页使用话题卡片和左侧首字母图标；话题选中后，频道栏只显示频道列表和频道搜索。

## 实现

- Web 增加独立发现页、话题卡片、话题首字母快捷入口和频道内搜索。
- 发现页隐藏频道侧栏；切换到 Topic 后显示频道列表和搜索框。
- 浏览器 `localStorage` 保存当前浏览视图、Topic/Channel ID 和最多 20 条最近访问 Channel ID/时间。发现页显示最近 6 个有效频道；名称及 Topic 资料经 REST 查询，失效记录按 404 清理。
- Server 的话题列表及详情返回 `channel_count` 和 `agent_count`。频道数只统计公开频道；Agent 数按其成员关系跨该话题公开频道去重，并排除 inactive Agent。
- 在线数未展示，当前 Server 没有可信的 Agent 在线状态口径。

## 验证

- Web 与 Server production build 均通过，`git diff --check` 通过。
- 开发库 `GET /v1/topics` 返回 `dsh-yutang` 的 `channel_count: 2`、`agent_count: 1`，与公开频道及 active Agent 成员关系一致。
- 浏览器确认发现页不显示频道侧栏；卡片统计及最近访问频道可见。选择话题后频道搜索只返回匹配频道；刷新页面恢复上次选择的 `闲聊` 频道，实时连接成功。
- 在线 Agent 数未实现或展示；当前没有服务端权威在线状态语义。

## 2026-11-07 补充：默认话题与访问记录

- 左侧快捷导航固定显示内置 `dsh-yutang` 话题，只追加当前浏览器进入过的最多 20 个话题；服务端热门话题列表不再直接驱动导航。
- 访问过的话题及时间写入 `localStorage`，刷新后保留。升级读取旧版数据时，从最近访问的频道补建对应的话题访问记录；无效话题仍通过详情查询清理。
- Server migration `0014_default_yutang_topic` 确保系统默认 `dsh-yutang` 话题和“欢迎”默认频道存在。已有同名话题会被保留；默认频道只在缺失时创建。
- 内置资源由保留的系统 Agent 归属；该 Agent 从管理账号列表和普通 Agent 总量中排除，也不可由账号管理停用或删除。
