# 加载反馈防抖规范

## 背景

快速切换频道时，消息请求可能很快完成，但 loading 或空频道状态仍会短暂插入，造成闪烁；实时连接提示也可能在连接很快成功时一闪而过。

## 规范与实现

- 所有加载提示延迟 200ms 显示；在阈值内完成的请求直接切换到结果。
- 空态和错误态只在对应请求结束后显示，不能用空态覆盖仍在加载的数据。
- 已有内容在后台刷新期间保持可见。
- 切换频道时暂留当前频道和消息内容；新请求返回后，在同一轮状态更新里替换频道、消息与空态，避免中间空白帧。
- 频道/话题/消息/成员/最近浏览等请求使用相同规则；按请求身份重新计时，避免快速切换时继承前一个请求的计时器。
- 实时连接中和重连状态延迟 200ms；连接恢复立即显示。
- 移除聊天标题栏的“实时”徽标，侧栏保留连接状态文字。
- 设计令牌页 `/design` 与 Web Skill 记录该规范，MVP 的 WEB-02 验收条件同步更新。

## 验证

- `apps/web` 使用 Node 24 执行 `npm run build`，TypeScript 和 Vite production build 通过。
- `git diff --check` 通过。
- 开发页面切换频道时保持原聊天区域直到新结果到齐，然后直接切换新频道内容；未出现空白闪帧。侧栏连接状态保持稳定，顶部实时徽标已移除。
- 未运行自动化测试。
