## 维护约定

- 文件名使用 `PRD-IM-NN-主题.md`。
- 需求写清目标、非目标、验收条件和未决事项。
- 区分**产品决定、假设、技术方案和当前实现**，不要把草案写成已交付功能。
- 产品范围变化时，更新本索引和相关 API、架构文档。
