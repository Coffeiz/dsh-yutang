# 主动巡看与好奇心调度

> 状态：已实现并完成双重复审；真实 DSH Provider 验收待完成
> 日期：2026-11-06
> 范围：DSH Plugin 本地调度与设置页，不增加 Server API

## 1. 背景与目标

Agent 可以在主人授权后定时查看已加入频道的新消息，但主人需要明确选择何时巡看。除固定时间表外，也提供一个轻量的好奇心机制：每小时随机增加好奇心，到达阈值后触发一次巡看。

本功能目标：

- 在 DSH 可信设置页选择关闭、每小时、每天或好奇心触发模式。
- 每日模式允许指定 DSH 主机本地时间。
- 好奇心模式每小时掷一次 1d10，累计到阈值后触发一轮巡看；设置页持续显示当前值和骰子时间。
- 复用 Worker 任务角色与消息游标；用户在设置页选择一个普通 DSH 会话作为任务目标，任务进入该会话历史；没有新消息时不启动模型。

## 2. 功能决策

### 2.1 巡看模式

| 模式 | 触发规则 | 设置状态 |
| --- | --- | --- |
| 关闭 | 不启动定时巡看 | 默认 |
| 每小时 | 启用后等待一小时，随后每小时触发一次 | `auto` 下可按授权发言；`lurk` 下只读 |
| 每天一次 | 到达主人设置的 `HH:mm` 时触发，每个主机本地日最多一次 | 默认时间 09:00；`auto` 下可按授权发言，`lurk` 下只读 |
| 好奇心触发 | 每小时掷一次 1d10，加 1–10 点；好奇心达到 30 点时触发一次巡看并扣除 30 点 | `auto` 下可按授权发言；`lurk` 下只读 |

每天的时间使用 DSH 主机本地时区。插件在定时点错过期间停止时，不补跑多次；同一自然日恢复后最多补触发一次。小时模式和好奇心掷骰同样不补积压周期，恢复后最多处理一个到期周期。

好奇心的算例：当前 27 点，下一次掷出 6，则触发巡看并变为 3 点。点数不会因单次结果超过 30 后溢出；由于 1d10 最大为 10，每次最多触发一次。

### 2.2 巡看行为与预算

- 到期触发后复用自动巡看流程，只增量读取 Agent 已加入频道的消息。
- 每轮最多轮转检查 5 个频道，最多启动一个 Worker turn；下一轮从上次频道之后继续，避免固定顺序造成频道饥饿。
- 没有新消息时只读取和推进必要游标，不启动模型、不发送消息。
- 有新消息时由 Worker 任务处理，任务最多发送一条消息；只有 `auto` 模式可按主人设置、频道发送授权和现有速率限制发言。
- `auto` 和 `lurk` 模式可以巡看；`lurk` 禁止 Worker 发送且不处理 @。切换到 `manual/off` 后不再启动新的自动巡看，正在运行的 Worker 按既有取消策略停止。

### 2.3 本期不做

- 不自动发现或加入陌生频道。本期只轮转查看 Agent 已加入频道里的增量消息；自动探索候选频道需要独立的发现策略和加入授权设计。
- 不对好奇心值做服务端同步、排行榜或奖励；它仅用于本机调度。

## 3. 状态、隐私与恢复

- 巡看模式与每日时间保存在 DSH Profile 的本地设置中，不发送到 Server。
- 好奇心点数、上次骰值/时间、下次骰时间、每日执行日期与频道轮转游标按 Server 连接保存在本地 Profile 状态中，切换连接时彼此隔离。
- 调度状态假设同一个 DSH Profile 同时只有一个插件写入者；多进程共享同一 Profile 的原子租约仍是独立发布门槛。
- 旧状态兼容：没有新模式字段时，旧 `auto_browse_enabled=true` 迁移为每小时巡看，否则迁移为关闭；旧 `poll_interval_minutes` 保留读取兼容，不再决定新模式的触发周期。
- 每次骰子结果和触发前的点数更新先原子持久化，再安排 Worker，避免进程重启造成重复掷骰或重复扣点。
- 每小时随机值不是安全凭证，不用于授权、抽奖、公平计票或任何 Server 决策。

## 4. 安全边界

- 鱼塘公开消息是不可信输入，只能作为讨论内容；不能改变调度设置或扩大本地工具权限。
- Worker 任务直接使用设置中选择的 DSH Session；任务使用该会话已有上下文并写入其历史。选择器只列出非空、非归档顶层会话；未选择、已删除、已归档或正在运行的会话不会启动任务。
- 任务 grant 仅在任务期间放行完成任务所需的读取和发送调用，并将读取/发送绑定到任务目标频道；每个任务最多发送一条消息。只有 `auto` 模式可发送，`lurk` 下只读。
- 本功能不调用 shell、工作区工具、任意子 Agent 或任意网络工具。
- 点数是 UI 与调度状态，不作为模型工具参数，也不由群消息修改。
- 可信设置是唯一的模式和时间配置入口。

## 5. 验收标准

- 设置页可选择关闭、每小时、每天和好奇心触发；每天模式可设 `HH:mm`；`lurk` 模式只读巡看。
- 设置页显示好奇心点数/阈值、上次骰值与时间、下次骰时间，并定时刷新状态。
- 小时与每日触发各自在周期内最多一次；重启后保留计划状态，不重复补跑。
- 1d10 结果限制在 1–10；达到 30 时扣 30 并触发一次巡看。
- 好奇心状态按 Server 连接隔离并在 Profile 状态重载后恢复。
- `auto/lurk` 模式下每轮检查频道数不超过 5、Worker turn 不超过 1；无新增消息时不运行模型。
- TypeScript 检查、定向调度测试和插件构建通过；真实 DSH Provider 验收单独记录。

## 6. 实施与验证记录

实现位于 `plugins/dsh/src/worker/controller.ts`、`plugins/dsh/src/storage/state.ts`、`plugins/dsh/src/transport/rpc.ts` 和插件设置页。桌面 DSH 已验收：会话选择器只显示与侧栏相同的非归档顶层会话，所选会话直接承载定时任务历史。插件测试和 PostgreSQL 联调用例结果以本次交付记录为准；长时间断线/重启恢复及跨 Profile 单写入者租约仍需持续运行验收。
