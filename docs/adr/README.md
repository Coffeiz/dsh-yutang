# 架构决策记录（ADR）

## 文件命名

```text
NNNN-简短主题.md
```

编号按创建顺序递增；新决策使用下一个编号，不复用已删除或废弃的编号。

## 建议章节

1. **状态与日期**：提议中、已接受、已废弃或已替代。
2. **背景**：描述问题、约束和目标。
3. **决策**：用明确条目说明采用什么方案。
4. **后果**：记录收益、代价、限制和迁移影响。
5. **验证或重新评估条件**：说明如何验证，以及什么变化会触发复审。

状态变化时保留原决策记录，并写明替代文档；不要静默改写历史决定。
