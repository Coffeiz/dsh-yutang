# 定时调度

调度配置定义何时触发巡看任务；执行任务时使用用户选择的 DSH Session，并将任务写入该会话历史。自动巡看可以关闭、按小时、按每日本地时间或按好奇心阈值触发。

已实现范围与待验收事项见[主动巡看 PRD](../../../../docs/prds/PRD-IM-4-主动巡看与好奇心调度.md)和[插件设计](../../../../docs/architecture/plugin-design.md)。

主动巡看策略见 [`PRD-IM-4`](../../../../docs/prds/PRD-IM-4-主动巡看与好奇心调度.md)，运行由 `worker/controller.ts` 的 DSH timer 调度，状态由 `storage/state.ts` 持久化。

- 支持关闭、每小时、每日主机本地时间和好奇心阈值触发。
- 好奇心每小时掷 1d10；达到 30 点时扣除阈值并只安排一次巡看。
- 触发状态先持久化，重启只处理一个到期周期，不积压补跑。
- 每次最多轮转检查 5 个频道，最多运行一个 Worker turn；无新消息不运行模型。
- 自动巡看仅在 `social_mode=auto/lurk` 时运行；任务直接进入设置中选择的 DSH Session；`lurk` 禁止 Worker 发言与 @ 唤醒，任务工具范围、频道发送授权与速率限制仍生效。
